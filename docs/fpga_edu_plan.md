# FPGA 설계 교육

- 목적 : 초보자에게 FPGA 로직 설계 능력을 단기간에 향상시키기.
- 실습보드 : Arty-7 (microblaze 실습 교육과 동일한 보드, 단 Microblaze는 사용하지 않는 예제 생성)
- 시뮬레이터 : Questasim - Visualizer 디버깅
- 쉬운 것부터 차근차근 기능이 추가되면서 Arty-7의 인터페이스를 최대한 활용할 수 있도록.
- 진입장벽을 최대한 낮추는 것이 중요. 툴에 대한 부담감을 없애야 함.
- 실습은 총 2일치 분량으로.
- 하루에 실습 최대 4가지 정도 - 오전 2가지, 오후 2가지

## 실습 슬라이드 구성 공통 요소

- 어떤 것을 설계해 볼지 간략하게 소개 및 다이어그램 svg 나 그림 첨부 활용으로 알기 쉽게 제시.
- 단계별로 무엇을 해야하는지 순차적으로 제시 
- 예제 코드 제공 , 코드에 대한 시뮬레이션 및 합성 결과를 시각적으로 첨부하여 실습결과를 알기 쉽게 제시. 그림이 필요한 경우 내가 직접 캡쳐 가능하니 placeholder 와 파일명 제시 형태로 진행. 
- 각 단계별로 힌트를 제시하여 막히는 부분이 없도록 함. 

## 커리큘럼 연계 — 2개월차 "설계 기반 검증" (Day 09~16)

> 본 설계 실습 철학을 V&V 과정 2개월차로 편성 (2026-06-19 확정).
> 기존 "QuestaSim 커버리지 검증" → **직접 설계 → QuestaSim/Visualizer 시뮬 → 검증** 흐름으로 전환.
> 검증 스킬(TB·SVA·커버리지)을 *자기가 만든 DUT* 위에서 학습 → 진입장벽 최소화.

| Day | 설계 주제 (Arty-7) | 검증 스킬 |
|-----|------|------|
| 09 | 조합논리 (스위치→LED, MUX) | QuestaSim·Visualizer 환경, 파형 읽기, 첫 stimulus |
| 10 | 순차논리 (클럭분주 blinker, 카운터, 버튼 디바운서) | 클럭/리셋 TB, self-checking 기초 |
| 11 | FSM (신호등 / RGB PWM / 버튼 시퀀스) | 상태 천이 검증, corner case |
| 12 | UART TX/RX (USB-UART 루프백) | 프로토콜 검증, scoreboard 개념 |
| 13 | (Day12까지 설계 재사용) | 재사용 TB 구조(driver/monitor/scoreboard), SVA assertion 기초 |
| 14 | (위 설계 적용) | 코드 커버리지 측정·해석, 커버리지 클로저 |
| 15 | 통합 미니 프로젝트 (UART로 LED 제어 / 스톱워치) | regression, 시뮬 검증 종합 |
| 16 | (Day15 설계) | Vivado 합성·구현·보드 다운로드, 시뮬 vs 실보드 대조 |

- 활용 인터페이스: 4 LED / 4 RGB LED / 4 슬라이드 스위치 / 4 푸시버튼 / USB-UART / 100MHz clk (Microblaze 미사용).
- Autocheck/Covercheck는 3개월차 Formal 블록(Week 9)으로 이동.

### Day 15 통합 미니 프로젝트 — 난이도별 4종 선택 (수강생 수준에 맞춰 택1)

| 난이도 | 프로젝트 | 핵심 블록 | 검증 포인트 |
|--------|----------|-----------|-------------|
| ★ 기초 | LED 패턴 컨트롤러 | 카운터 + MUX + 스위치 모드 선택 | 모드별 출력, 경계 카운트 |
| ★★ 표준 | 스톱워치 (버튼 start/stop/reset) | FSM + BCD 카운터 + 디바운서 | FSM 천이, 디바운스, 자리올림 |
| ★★★ 응용 | UART 명령 → LED/RGB 제어 | UART RX + 명령 디코더 + 레지스터 | 프로토콜, 명령 파싱, scoreboard |
| ★★★★ 도전 | UART 콘솔 + PWM RGB 디머 | UART RX/TX + PWM + FSM | 양방향 통신, PWM 듀티, 통합 회귀 |

- 공통 골격(클럭/리셋/TB 하네스)은 동일하게 제공 → 수강생은 코어 로직에 집중.
- Day 16에서 선택 프로젝트를 Vivado 합성·구현 후 실보드로 검증.
