# cov_hole — 커버리지 홀 분석 · 자극 보강 · 재측정

실습1의 낮은 커버리지를 출발점으로, **리포트의 홀에서 누락된 시나리오를 역추적**하고
그 자극을 TB 에 추가해 커버리지를 끌어올린다. 구현 대상은 `boost_scenario` 태스크.

## 홀 → 자극 역추적

| 리포트가 가리키는 홀 | 누락된 시나리오 | 추가 자극 |
|----------------------|-----------------|-----------|
| `en` 분기 false 미도달 | 채널 disable 안 해봄 | `en=0` 구간 삽입 |
| WARN→MONITOR 천이 0 | 일시 초과 회복 안 해봄 | vote 인가 후 즉시 제거 |
| `vote` condition 곱항 미달 | `sensor=111` 만 인가 | 110·101·011·단일 센서 다양화 |
| LATCH `if(clear)` false만 | clear 인가 안 해봄 | LATCH 도달 후 `clear` 펄스 |

핵심 : **커버리지 홀은 "안 해본 자극"의 목록**이다. 홀을 읽으면 무엇을 더 시험해야
하는지 알 수 있다 — 이것이 커버리지의 관리적 가치(검증 계획 피드백).

## 실행

```bash
cd sim
make            # 보강 TB 로 재측정
make report     # 실습1 대비 branch/condition/FSM 상승 확인
make html
make clean
```

## 남는 것

보강 후에도 100% 가 아니다. `default:` 분기는 상태가 2비트 전수(0~3)라 **원천 도달불가** —
어떤 자극으로도 못 메운다. 이 홀은 실습4(cov_closure)에서 **사유와 함께 제외**한다.
